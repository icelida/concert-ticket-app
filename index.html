🔎 ส่วนที่ 3A · Unsupervised Anomaly Detection: ตรวจจับบอทที่ไม่มี Label (ต่อยอดครึ่งหลัง)

        

          ทำไมต้องใช้ Unsupervised Anomaly Detection? โมเดล Supervised ในแท็บ 2 เรียนรู้จากบอทที่เคยติด Label ไว้แล้ว (เช่น บอทกดรัว) แต่ในงานจริงจะมี บอทสายพันธุ์ใหม่ (Zero-Day / Distributed Bot) ที่ยังไม่มี Label ในชุดฝึก (ตั้งใจกดช้าเหมือนคน แต่ใช้ IP ซ้ำจำนวนมาก + เมาส์ลากเส้นตรงผิดธรรมชาติ) จึงต้องใช้ PCA (ลดมิติ) + Clustering / Anomaly Detection ค้นหาจุดที่เบี่ยงเบนจากกลุ่มคนส่วนใหญ่โดยไม่ต้องพึ่งพา Label
        

        

          
          
          ฟีเจอร์พฤติกรรม 7 ตัว → StandardScaler → PCA 2D Biplot + Anomaly Score
        

      


      

        

          
Confusion Matrix (ไม่ใช้ Label ตอนฝึก)

          

          

        

        

          
การกระจาย Anomaly Score & เกณฑ์ตัดสิน

          
        

        

          
PCA Explained Variance (ฟีเจอร์พฤติกรรม)

          
        

      


      

        

          
PCA 2D Biplot ของพฤติกรรมบัญชี & จุดที่ถูกติดธง Anomaly

          
          
จุด = บัญชีบนแกน PC1–PC2 · เส้นสีเหลือง = ทิศทางอิทธิพลของฟีเจอร์ (PCA Loadings / Biplot) · วงกลมขอบขาว = บัญชีที่ถูกติดธงว่าเป็น Anomaly

        

        

          
เปรียบเทียบ 5 วิธี Unsupervised Anomaly vs Supervised

          

          

            สังเกตคอลัมน์ Recall (Zero-Day): โมเดล Supervised แทบจับบอทสายพันธุ์ใหม่ที่ไม่มีใน Label ไม่ได้เลย ในขณะที่ Unsupervised Anomaly Detection จับได้สูงโดยไม่ต้องใช้ Label!
