🔎 ส่วนที่ 4A · Unsupervised Anomaly Detection: ตรวจจับบอทไร้ Label (ต่อยอดครึ่งหลัง)

        

          ทำไมต้องใช้ Unsupervised Anomaly Detection? โมเดล Supervised ในแท็บ 3 เรียนรู้จากบอทที่เคยติด Label ไว้แล้ว (เช่น บอทกดรัว) แต่ในงานจริงจะมี บอทสายพันธุ์ใหม่ (Zero-Day / Distributed Bot) ที่ยังไม่มี Label ในชุดฝึก (ตั้งใจคลิกช้าเหมือนคน แต่ใช้ IP ซ้ำจำนวนมาก + เมาส์ลากเส้นตรงผิดธรรมชาติ) จึงต้องใช้ PCA (ลดมิติ) + Clustering / Anomaly Detection ค้นหาจุดที่เบี่ยงเบนจากกลุ่มคนส่วนใหญ่โดยไม่ต้องพึ่งพา Label
        

        

          
          
          ฟีเจอร์พฤติกรรม 7 ตัว → StandardScaler → PCA 2D Biplot + Anomaly Score

เปรียบเทียบ 5 วิธี Unsupervised Anomaly vs Supervised

          

          

            สังเกตคอลัมน์ Recall (Zero-Day): โมเดล Supervised แทบจับบอทสายพันธุ์ใหม่ที่ไม่มีใน Label ไม่ได้เลย ในขณะที่ Unsupervised Anomaly Detection จับได้สูงโดยไม่ต้องใช้ Label!
